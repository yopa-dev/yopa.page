{{- /* Returns the robots meta value for a page, or "" when search engines may index it. The head partial and the sitemap both use this, so a page that asks search engines to skip it is never listed in the sitemap. - robots front matter wins (for example "noindex, follow"). - noindex: true keeps its original meaning, "noindex, nofollow". - Automatic tag/category term lists, including their pagers, default to "noindex, follow" regardless of post count. Google live tests still reported soft 404 on a two-post term and a two-post last pager. Counts are not a quality threshold; these lists are navigation, not search landing pages. Taxonomy directories (kind taxonomy) remain eligible. - Other sections opt out explicitly in front matter, regardless of size. - The /blog/ section list duplicates /articles.html. CloudFront redirects it; this keeps it out of the index and the sitemap as well. */ -}} {{- $robots := "" -}} {{- with .Params.robots -}} {{- $robots = . -}} {{- else -}} {{- if .Params.noindex -}} {{- $robots = "noindex, nofollow" -}} {{- else if and (eq .Kind "section") (eq .Section "blog") -}} {{- $robots = "noindex, follow" -}} {{- else if eq .Kind "term" -}} {{- $robots = "noindex, follow" -}} {{- end -}} {{- end -}} {{- return $robots -}}
